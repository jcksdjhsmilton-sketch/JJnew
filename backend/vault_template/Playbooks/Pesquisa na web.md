# Pesquisa na web
1. `web_search` com 2 a 3 consultas curtas e diferentes (kind=news para atualidades).
2. Escolha as 2 ou 3 fontes mais confiáveis (oficiais, docs, imprensa séria).
3. `fetch_url` em cada uma; se a página for longa, use `start` para paginar.
4. Cruze as fontes; se divergirem, diga isso.
5. Responda curto, cite a fonte e salve resumos úteis com `brain_note`.
