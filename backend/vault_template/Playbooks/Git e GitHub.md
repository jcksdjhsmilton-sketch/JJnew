# Git e GitHub
- Clonar: `git clone URL` (use `--depth 1` para repos grandes).
- Fluxo: `git checkout -b nome`, editar, `git add -A`, `git commit -m msg`, `git push -u origin nome`.
- Push autenticado: `https://x-access-token:$GITHUB_TOKEN@github.com/dono/repo.git`.
- Conflito: `git status`, edite os marcadores `<<<<<<<`, `git add`, `git commit`.
- Nunca imprima tokens nos logs.
