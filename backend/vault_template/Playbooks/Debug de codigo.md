# Debug de código
1. Reproduza o erro e copie a mensagem exata.
2. Leia o traceback de baixo para cima: o erro real está na última linha.
3. `read_file` no trecho citado e `grep` para achar usos relacionados.
4. Corrija com `edit_file` (mudança mínima) e rode de novo para confirmar.
5. Se persistir, isole com um script pequeno em `python_exec`.
